# Lancylot2004 Tap

## How do I install these formulae?

`brew install lancylot2004/tap/<formula>`

Or `brew tap lancylot2004/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "lancylot2004/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
